====================================================
  יועץ בנייה — הדרכת התקנה ברשת פנימית סגורה
====================================================

קובץ זה נכלל בחבילה ונגיש גם ללא חיבור לאינטרנט.

====================================================
  שלב 1: הכנת החבילה (מחשב עם אינטרנט)
====================================================

דרישות:
- Node.js גרסה 18 ומעלה (https://nodejs.org)
- Git (להורדת הקוד)

הפקודות:
  git clone https://github.com/razool13/construction-advisor.git
  cd construction-advisor
  npm install
  npm run build

לאחר הפקודות תיווצר תיקיית "dist/" — זו החבילה המוכנה.

====================================================
  שלב 2: העתקה למחשב הפנימי
====================================================

העתק את כל תיקיית "dist/" למחשב הפנימי.
ניתן באמצעות USB, תיקיית רשת, או כל דרך אחרת.

מבנה הקבצים:
  dist/
  ├── index.html          ← הקובץ הראשי
  ├── SETUP_OFFLINE.txt   ← קובץ הדרכה זה
  └── assets/
      └── index-XXXXX.js  ← קוד האפליקציה

====================================================
  שלב 3: הפעלת האפליקציה
====================================================

  *** הדרך הפשוטה ביותר ***

  פתח את הקובץ dist/index.html בדפדפן בדאבל-קליק.
  זהו! האפליקציה תיפתח מיידית.

  נבדק ועובד ב: Chrome, Edge, Firefox

  --- אם רוצים להשתמש בשרת (אופציונלי) ---

  אפשרות א' — Node.js serve:
    npx serve dist -s -l 3000
    פתח: http://localhost:3000

  אפשרות ב' — Python:
    cd dist && python3 -m http.server 3000
    פתח: http://localhost:3000

  אפשרות ג' — nginx (לסביבת ייצור):
    server {
      listen 80;
      root /path/to/dist;
      index index.html;
      location / {
        try_files $uri $uri/ /index.html;
      }
    }

====================================================
  שלב 4: הגדרת AI פנימי
====================================================

1. לחץ על הגדרות AI (אייקון גלגל שיניים)
2. בחר בלשונית "ChatGPT"
3. הזן את ה-API Token הפנימי שלך
4. בשדה "Endpoint מותאם אישית" הזן:
   http://YOUR-INTERNAL-AI-SERVER:PORT/v1

   דוגמאות נפוצות:
   - Ollama:        http://localhost:11434/v1
   - LM Studio:     http://localhost:1234/v1
   - vLLM:          http://your-server:8000/v1
   - LocalAI:       http://your-server:8080/v1

5. בשדה "שם מודל" הזן את שם המודל הפנימי:
   דוגמאות: llama3, mistral, qwen2.5, phi-3

6. לחץ "בחר ספק זה" אם לא בחרת עדיין

====================================================
  שלב 5: דרישת CORS (חשוב!)
====================================================

אם פתחת מ-file:// (דאבל-קליק) או משרת:
השרת הפנימי של ה-AI חייב להחזיר headers של CORS:

  Access-Control-Allow-Origin: *
  Access-Control-Allow-Headers: Authorization, Content-Type
  Access-Control-Allow-Methods: POST, OPTIONS

רוב שרתי AI (Ollama, LM Studio, vLLM) תומכים ב-CORS
כברירת מחדל. אם לא — הוסף nginx reverse proxy.

Ollama — הפעלה עם CORS:
  OLLAMA_ORIGINS="*" ollama serve

====================================================
  מה עובד / מה לא עובד
====================================================

עובד:
  + צ'אט AI (עם API פנימי תואם OpenAI)
  + ניהול פרויקט — לוח גנט, תקציב, יומן עבודה
  + ניהול קבלנים ומסמכים
  + ייצוא/ייבוא נתונים (JSON מקומי)
  + כל הנתונים נשמרים בדפדפן (localStorage)

לא עובד ברשת סגורה:
  - גיבוי ל-Google Drive (דורש גישה לגוגל)
  - Google Calendar / Tasks (דורש גישה לגוגל)
  - גופן Noto Sans Hebrew (ייפול לגופן ברירת מחדל)

====================================================
  פתרון בעיות
====================================================

בעיה: הצ'אט מחזיר שגיאת "Failed to fetch"
פתרון: בדוק שהשרת הפנימי פועל ושה-CORS מוגדר.
        בדוק בדפדפן: http://YOUR-AI-SERVER:PORT/v1/models

בעיה: דף לבן כשפותחים מ-file://
פתרון: נסה דפדפן אחר (Chrome/Edge מומלצים).

בעיה: הגופנים לא טוענים
פתרון: קוסמטי בלבד — האפליקציה תעבוד עם גופני מערכת.
